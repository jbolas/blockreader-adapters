# blockreader-adapters — read from block device container files

This Cargo workspace provides small adapters to make local-file block device container files (.e01, .aff4, .vmdk, e.g.) available for random-access reading via the [`blockreader`](https://github.com/jbolas/blockreader) trait.

Please see [`aff4tools`](https://github.com/jbolas/aff4tools) and [`aff4-blockreader`](pending) for examples of how an AFF4 forensic container can be read using a `BlockReader`.
