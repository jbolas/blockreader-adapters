# aff4-blockreader — implements BlockReader for AFF4 containers

This small crate adapts an AFF4 container to the [blockreader](https://github.com/jbolas/blockreader) trait, so a filesystem parser can read the disk image. It relies on [aff4tools](https://github.com/jbolas/aff4tools) to parse the AFF4 v1.0 format. 

## Usage example

```rust
use aff4_blockreader::Aff4Source;
use blockreader::BlockReader;

// An example parser that reads basic info about a disk image
fn survey(source: &dyn BlockReader) {
    let sector = source.sector_size();
    println!(
        "{} bytes, {} byte sectors ({:?})",
        source.size(),
        sector.bytes(),
        sector.basis()
    );
}

let source = Aff4Source::open("evidence.aff4").unwrap();
survey(&source);
```
